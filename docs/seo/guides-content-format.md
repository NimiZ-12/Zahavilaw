# פורמט הגשת מדריך - מדור המדריכים בדיני עבודה

> מסמך עבודה לסוכן השיווק. כל מדריך מוגש בדיוק במבנה הזה, אחרי אישור
> מילה-במילה של רון. הסוכן המפתח מזין את התוכן כפי שהוא ואינו מנסח מחדש.
> המבנה הטכני המחייב: `src/i18n/guides/types.ts` (טיפוס `Guide`).

## כללים שחלים על כל הטקסט

- עברית בלבד. המדור חד-לשוני.
- אין מקף ארוך (`—` או `–`) - מקף רגיל `-` בלבד.
- כללי לשכת עורכי הדין (פרסומת): אין מחירים או "חינם", אין סופרלטיבים
  ("המוביל", "מומחה"), אין הבטחות תוצאה, אין השוואות למשרדים אחרים.
  אמירות משפטיות מסויגות ("ככלל", "עשוי", "בהתאם לנסיבות").
- שפה אנושית: משפטים קצרים, גוף שני, בלי ז'רגון מיותר.

## השדות, אחד-אחד

| שדה | מה זה | מגבלות |
|---|---|---|
| `slug` | מקטע הכתובת, באנגלית, אותיות קטנות ומקפים | קבוע לתמיד; לא משתנה אחרי פרסום |
| `shortName` | שם קצר לפירורי הלחם ולהודעת הוואטסאפ | 2-4 מילים |
| `meta.title` | כותרת לגוגל | עד 60 תווים |
| `meta.description` | תיאור לגוגל | עד 155 תווים |
| `h1` | הכותרת הראשית בעמוד | שאלה או פנייה ישירה |
| `answer` | פסקת התשובה שבראש העמוד | 40-60 מילים; עונה על השאלה של ה-h1 ישירות, בלי "זה תלוי" כפתיח; זה הטקסט שמנועי החיפוש מצטטים |
| `audience` | `employee` / `employer` / `both` | |
| `author` | `anat-zahavi` או `ron-zahavi` | הכותב/ת שבאמת אחראי/ת לתוכן |
| `published` | תאריך פרסום ראשון | YYYY-MM-DD |
| `updated` | תאריך העדכון האחרון | YYYY-MM-DD; לעדכן בכל שינוי תוכן |
| `sections[]` | גוף המדריך | כל מקטע: `q` (כותרת בניסוח שאלה), `answer` (משפט-שניים של תשובה ישירה), `body` (פסקאות הסבר), `bullets` (אופציונלי) |
| `actions[]` | "מה כדאי לעשות עכשיו" | בדיוק 3 צעדים: `title` קצר + `body` |
| `faq[]` | שאלות נפוצות | 4 עד 6; התשובות עומדות בפני עצמן |
| `related[]` | נושאים קשורים | קישורים לעמודי הנחיתה (`/he/lp/...`) ולעמוד דיני עבודה |
| `sources[]` | מקורות | סעיפי חוק ופסיקה; `href` אופציונלי |

## מה קורה אחרי ההגשה

1. הסוכן המפתח יוצר `src/i18n/guides/<slug>.ts` עם התוכן כפי שהוא,
   ורושם את המדריך ב-`src/i18n/guides/index.ts`.
2. בנייה ובדיקות (`npm run build`, `npm run lint`, `verify-site`).
3. העלאה ל-staging; רון מאשר בתצוגה המקדימה.
4. מיזוג לפרודקשן ודיווח הכתובת החדשה לרון, כדי שסוכן השיווק יבקש
   עבורה אינדוקס ב-Search Console.

המדריך הראשון גם מדליק אוטומטית את: עמוד `/he/guides`, הקישור בפוטר
העברי, בלוק המדריכים בעמוד דיני עבודה, שורות המדריכים ב-`llms.txt`
והרישום בסייטמאפ. לפני המדריך הראשון - כל אלה כבויים בכוונה.
